# Biblioteca de objetos do BrasBim

Objetos feitos do zero para o BrasBim, sob a licença Creative Commons Atribuição 4.0 Internacional (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/deed.pt-br

Gerada por `scripts/gerar_biblioteca.py` a partir de `brasbim/core/objects/builtin.py`. As medidas são as usuais no mercado brasileiro, como ponto de partida; a altura da bacia acessível fica a conferir na NBR 9050.
