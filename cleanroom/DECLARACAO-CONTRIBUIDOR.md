# Declaração clean‑room do contribuidor

Todo commit deve ter `Signed-off-by:` (DCO 1.1, https://developercertificate.org), usando `git commit -s`.
Antes da primeira contribuição, cada pessoa adiciona esta declaração ao PR:

> Declaro que:
> 1. A contribuição é de minha autoria ou vem de fonte com licença compatível, indicada no PR.
> 2. Não consultei código‑fonte, código descompilado, símbolos de binários, nem material
>    de engenharia reversa de software proprietário (incluindo a pasta `_restrito/`) para produzi‑la.
> 3. Não copiei textos, ícones ou imagens de software proprietário.
> 4. Se já tive acesso a esse tipo de material, informei no PR e me registrei em
>    `cleanroom/REGISTRO-DE-ACESSO.md`.
>
> Nome / data
